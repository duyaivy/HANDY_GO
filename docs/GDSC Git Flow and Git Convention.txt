Git Flow

Feature: feature/[Project code]-[ID]-[task_name]
Bugfix: bugfix/[Project code]-[ID]-[task_name]
Hotfix: hotfix/[Project code]-[ID]-[task_name]

Eg:
	feature/SC-2-build_base_code
	bugfix/SC-3-fix_bug_not_show_header
	hotfix/SC-4-change_text_color
